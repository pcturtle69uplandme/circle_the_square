## QA before accepting a plate
1. **Set match** — brick/black banding, walnut, grey carpet tile, Jan's black-framed
   glazed door with raised blinds. Reject if the corridor turns generic-office.
2. **Identity** — Jan's side parting + belly + navy suit; Chris light blue shirt, lean;
   Rick grey polo, broad, buzzcut; Sharon auburn wavy hair. Reject drift.
3. **Geography** — Jan's door LEFT, hot-desks RIGHT, window at the far end. Reject mirrored plates.
4. **No stray lettering** — check lanyards/signage for garbled text.
5. **Aspect** — match the anchor's ~2.39:1 where the model allows it.
