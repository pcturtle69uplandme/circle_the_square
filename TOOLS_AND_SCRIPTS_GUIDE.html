02 Tool legend — plain English

Every name in this document, explained without jargon, with a link to look it up. If you only read one section, read this one.

The vocabulary

TermWhat it actually means
ModelA trained AI file (often several gigabytes). You give it a text prompt; it gives back an image, a video, or audio. The model is the "engine"; the script is the "ignition key".
CheckpointOne saved version of a model, usually a .safetensors file. "RealVisXL V4.0" and "V5.0" are two checkpoints of the same family.
Parameters (3.3B)How big the model's brain is. 3.3 billion parameters = bigger, better, slower, more VRAM. "Large" beats "medium" beats "small".
Local vs cloudLocal = runs on your own graphics card. Free per-run, unlimited, private, but you need the hardware. Cloud = runs on someone else's servers. Costs money or quota, needs internet.
GPU / VRAM / CUDAThe graphics card, its dedicated memory, and NVIDIA's software layer that lets AI use it. "Out of VRAM" = the model is too big for the card, not a bug.
fp16Half-precision maths. Roughly halves VRAM use and doubles speed, with no visible quality loss. Always on in these scripts.
Inference stepOne denoising pass an image model makes. More steps = slower, usually cleaner. "Lightning" models get there in 8 steps instead of 30.
CFG / guidance_scaleHow literally the model obeys your prompt. Too low = it ignores you. Too high = harsh, clipped, over-cooked output. The score clipping was fixed by dropping this from 3.0 to 2.0.
TemperatureRandomness. Lower = safer and more repetitive; higher = wilder. 0.85 is the current setting for the score.
SeedThe random starting number. Same seed + same prompt + same model = same output. Change it to get a different roll of the dice.
RerollGenerate again with a new seed because the last one wasn't right. Normal and expected — budget for it.
Text-to-image / image-to-videoWhat goes in → what comes out. "Image conditioning" means you also hand it reference pictures so it copies the look.
Identity lockThe trick that stops your character's face changing between shots — you feed a reference photo through IP-Adapter so every frame matches.
Node graphComfyUI's visual wiring diagram of boxes and cables. Our scripts skip the diagram and post the equivalent JSON straight to its API.
FiltergraphFFmpeg's instruction string for transitions, fades and layering. What video_wipe_editor.py builds for you.
MuxMarrying a video track and an audio track into one file. The last step of every trailer build.
MasterThe final rendered file you actually show people — e.g. SMALL_STAKES_TRAILER_MASTER_60S.mp4.
QuotaA usage allowance that refills (daily or monthly) rather than a bill. Google AI Pro works this way.
OAuth / AQ. tokenA temporary login pass, not a permanent password. Expires in hours. The agy CLI mints fresh ones.

How to keep it cheap
  • Reroll on schnell, finish on dev. Find the composition at 0.24p, then re-render the ~20 keepers at 2p. Never iterate on pro.
  • Veo is the real constraint, not money. It costs £0 but the monthly cap is finite. Lock the shot on a cheap still before spending a video generation.
  • Push repeated work local. Score, voice and assembly get regenerated dozens of times — all of it free on your own card.
  • The bill is rerolls. One clean pass over everything is under 30p. A 5× reroll factor on pro is over £11. Prompt discipline is the budget.

07 Auth & standing rules

Google auth — the AQ. token model

This is the part that breaks most often, so it is worth understanding rather than pattern-matching.

  • Scripts call the google-genai SDK's interactions.create() endpoint. That endpoint requires an AQ. OAuth token — a plain AIza… API key will not work.
  • The agy CLI mints that token and exposes it as GEMINI_API_KEY. Tokens expire after a few hours; that is normal, not a fault.
  • The refresh token lives at %USERPROFILE%\.gemini\oauth_creds.json.
  • GOOGLE_API_KEY must be unset in the child process — if present it overrides GEMINI_API_KEY and auth fails confusingly.

Always go through the wrapper, which refreshes the token then shells out with a clean env:

python run_location_sheets.py

Internally: run agy --print to force a token refresh → read GEMINI_API_KEY → spawn generate_location_sheets.py with that token and with GOOGLE_API_KEY popped.

Never do these
  • setx GEMINI_API_KEY / setx GOOGLE_API_KEY — a stale machine-level env var poisons every future run.
  • Hand-pasting AQ. keys — they expire in hours.
  • Confusing the AI Pro subscription (consumer OAuth) with API credits (separate billing). The pipeline is subscription-only by design.

On auth failure: re-run the wrapper; if it still fails, open a fresh agy session (the token refreshes on startup) and retry. Full rule: .agents/rules/google_auth.md.

Music rule — MusicGen Large only

Standing user directive · .agents/rules/neural_ai_music_only.md

All music, score and soundtrack must come from a MusicGen Large 3.3B checkpoint, default facebook/musicgen-stereo-large. Two hard prohibitions:

  1. No synthetic/algorithmic audio — no sine/saw ostinatos, no pitch-step loops, no mathematically generated music.
  2. No downgrading to -medium, -small, or any other smaller checkpoint for deliverables.

Also mandated: 32kHz stereo output, full-duration max_new_tokens blocks crossfade-stitched so the score covers the closing card and final fade with no gap, and GPU execution (device="cuda", fp16) — CPU is prohibitively slow at 3.3B.

The nine create_*.py audio scripts predate this rule and violate prohibition #1. They are kept for history only — see the index below.

09 Runbooks

A · Rebuild the local stack on a fresh machine

# 1. CUDA PyTorch first — everything else depends on it
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install transformers diffusers accelerate safetensors soundfile moviepy imageio-ffmpeg pillow scipy numpy

# 2. Confirm the GPU is actually visible
python test_ltx_env.py          # prints CUDA, GPU name, free/total VRAM

# 3. Pull the mandatory music model (3.3B, several GB)
python download_musicgen_large_complete.py

# 4. ComfyUI + identity models (only if doing local stills / voice)
#    clone ComfyUI to C:\ai\ComfyUI\ComfyUI, then:
python download_realvisxl.py        # 6.46 GB SDXL checkpoint
python download_identity_models.py  # IP-Adapter Plus + CLIP-ViT-H-14
python test_comfyui_nodes.py        # confirm ComfyUI sees them
python check_ipadapter_nodes.py     # confirm the custom nodes loaded

B · Regenerate the score and re-master a trailer

# 1. Generate the cue (GPU, stereo 3.3B, several minutes)
python generate_mockumentary_score_stereo_gpu.py
#    -> audio-refs/musicgen_mockumentary_score.wav

# 2. Rebuild the master over it
python build_small_stakes_trailer.py   # or build_paper_trail_trailer.py

# 3. QA the result
python verify_orchestral_audio_levels.py   # levels across the whole cut
python analyze_master_audio_outro.py       # score covers the end card?
If the score clips or glitches

Lower guidance_scale (3.0 → 2.5 → 2.0) and temperature (→ 0.85) in the generation script. That exact adjustment is what fixed the earlier clipping, and the current mockumentary cue ships with those values.

C · Generate a Veo shot (manual, subscription)

  1. Open aistudio.google.com and sign in.
  2. Pick Veo 3.1 from the model dropdown.
  3. Open featurette_prompt_engine.md, find the shot (e.g. S01), copy its VIDEO PROMPT block.
  4. Upload the 2–3 reference images that shot lists as image conditioning.
  5. Set duration per the shot spec (5–8s; 8s generates best).
  6. Generate (~2–5 min), download the .mp4, save to clips\S01_office_establishing.mp4 (name per the workflow table).
  7. Run the shot's GATE CHECK from the prompt engine. Pass → next shot. Fail → tweak prompt → regenerate.

Full 19-shot queue with filenames and per-shot durations: VIDEO_GENERATION_WORKFLOW.md.

11 Gotchas & known issues

1 · 44 scripts hardcode a directory that no longer exists

Two thirds of the Python files contain absolute paths under C:\ai\Circle the Square\ — a location that is not present on this machine. The repo actually lives at C:\kontitemp\ai\circle_the_square. Those scripts will fail at the first file operation, or silently write into a directory tree nobody reads.

Only build_small_stakes_trailer.py and build_paper_trail_trailer.py use the correct pattern:

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
clips_dir = os.path.join(BASE_DIR, "clips")

Port older scripts to that pattern as you touch them, rather than doing one big risky sweep.

2 · build_action_trailer_master.py points at a score file that isn't there

It references audio-refs/musicgen_calm_mockumentary_score.wav. The folder only contains musicgen_mockumentary_score.wav. Either the file was renamed or never committed — fix the reference before running.

3 · Two scripts quietly violate the music rule

generate_neural_ai_score_large.py is named "large" but loads facebook/musicgen-small. generate_studio_musician_score.py loads musicgen-medium. Both are below the mandated 3.3B floor. Reach for the *_stereo_gpu.py scripts instead.

4 · The synthetic-audio scripts are the tempting wrong path

They are the only audio generators that run without torch or a GPU, so they will "just work" on a stripped machine while the correct ones fail. That's exactly the trap the standing rule exists to prevent.

5 · Auth failures are almost always GOOGLE_API_KEY

If GOOGLE_API_KEY is set anywhere in the environment it shadows GEMINI_API_KEY and the AQ. token never reaches the SDK. Check the machine-level env vars before debugging anything else.

6 · FFmpeg comes from pip, not the system

Every script resolves the binary through imageio_ffmpeg.get_ffmpeg_exe(). Don't "fix" a missing-FFmpeg error by installing FFmpeg system-wide — install imageio-ffmpeg.

7 · Veo 2 is dead

Deprecated June 2026. VIDEO_GENERATION_WORKFLOW.md still says "select Veo 2 or Veo 3" in places — always pick Veo 3.1.

8 · Gitignored, so not recoverable from the repo

.env, __pycache__/, *.log, clips/temp_*.mp4, frames/. Anything in those paths lives on one machine only.

9 · gen_image.py is a single point of failure outside version control

Five scripts depend on C:\AI\AI\gen_image.py — it holds the fal.ai integration and the API key. It is not in this repo, not backed up by backup-to-github, and not on this machine. If that file is lost, all cloud still generation stops and has to be rewritten from scratch. Worth copying into the repo (with the key kept in .env, which is gitignored) the next time you have access to it.
