▶️ How to Use Google Flow — Shot by Shot
1
Open Google Flow Go to labs.google/fx/tools/flow and sign in with your Google account. Your AI Pro subscription is detected automatically — 1,000 credits unlocked.
2
Start a new project Click "New Project". Give it a name like "Circle the Square — S01".
3
Select Veo 3.1 in the model dropdown Make sure you select Veo 3.1 (not Lite, not Fast) for best quality. Lite/Fast use fewer credits but produce lower quality.
4
Upload your reference images Open featurette_prompt_engine.md for the current shot. Find the "📎 Attach These Images" table. Upload those exact 2–3 files from your building-reference/use-images/ and character-refs/ folders.
5
Paste the Video Prompt Copy the VIDEO PROMPT block for the shot. Paste it into Flow's prompt field.
6
Paste the Audio Prompt Copy the AUDIO PROMPT block and paste into the native audio field. This lets Veo 3.1 generate ambient sound + SFX directly in the clip.
7
⚠️ Set outputs to 1 Check the "Number of outputs" setting before generating.
⚠️ Default is often 2 — this costs 40 credits instead of 20. Always set to 1 unless you want variants.
8
Generate — wait 2–5 minutes Do NOT refresh the page while generating — a failed/refreshed generation still counts as a used credit.
9
Download the .mp4 Save to C:\ai\Circle the Square\clips\S##_name.mp4 using the shot filename from the Shot Tracker tab.
10
Gate check → approve → next shot Watch the clip. Run the gate check from featurette_prompt_engine.md. If approved, update the Shot Tracker and move to the next shot.
⚠️ Critical Rules
❌ Never set outputs to 2
Costs 40 credits instead of 20. Always set to 1.
❌ Never refresh during generation
Failed/refreshed generations still consume credits.
⚠️ Always attach reference images
Without them Veo generates a generic office, not The Triangle Building.
⚠️ Gate check before next shot
If S01 looks wrong, fix the STYLE ANCHOR before generating S02 or you'll waste credits on 18 more wrong clips.
✅ Use the STYLE ANCHOR on every shot
The shared style anchor in featurette_prompt_engine.md keeps all 19 clips looking like the same show.

💡 Credit Tips
Set outputs to 1, not 2
Default is often 2 variants. That doubles your credit cost per shot from 20 to 40.
Approve stills before spending video credits
Get me to generate a still frame gate check first (free with your image budget). Only open Flow once the character + location look is confirmed.
Don't refresh while generating
Cancelled/failed generations still consume credits. Wait for the result even if it seems stuck.
Credits do not roll over
Monthly allocation. Use them or lose them. If you have leftover, spend on extra variants of complex shots.
